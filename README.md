# Simulador de gestión de pedidos:

Primer proyecto de mis estudios de Python. Es un programa de consola para registrar pedidos y calcular los portes de envío.

# Funcionalidades 

- Menú con tres opciones: Registrar, consultar y cancelar pedido.
- Registro de pedidos: Fecha, usuario autorizado, código de cliente, material y valor.
- Cálculo de portes: Los pedidos por debajo de 150 € pagan 7,50 € de portes; a partir de 150 € el envío es gratuito.
- Confirmación del cliente antes de aplicar los portes.

## Estado del proyecto

Proyecto de aprendizaje en desarrollo. Las opciones 2 (consultar pedido) y 3 (cancelar pedido) todavía no están implementadas.

# Conceptos practicados

Variables y constantes, `input` y `print`, condicionales (`if`/`elif`/`else`), diccionarios, f-strings y `exit()`.
